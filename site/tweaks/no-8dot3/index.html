Stop creating short file names

Advanced · Small gain · Windows 10 and 11

What it does

Windows creates an old DOS-style short name for every new file. Turning that off saves work in folders with thousands of files.

CategorySystem and security
TierAdvanced: trades some power use or a convenience for lower latency.
Expected differenceSmall gain
Needs adminYes
RestartNot needed
Framecalm presetsExtreme

The trade-off

Very old 16-bit programs may not find files. Existing short names stay.

Exactly what it changes

  • HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\NtfsDisable8dot3NameCreationSet to 1 · Windows default: 2

Do it by hand

Open Command Prompt as administrator and run:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\FileSystem" /v "NtfsDisable8dot3NameCreation" /t REG_DWORD /d 1 /f

To undo it:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\FileSystem" /v "NtfsDisable8dot3NameCreation" /t REG_DWORD /d 2 /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
