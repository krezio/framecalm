Turn off Copilot in Windows

Safe · Small gain · Windows 10 and 11

What it does

Removes the Copilot sidebar and its background process.

CategoryBackground apps
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceSmall gain
Needs adminYes
RestartNeeded before it takes effect
Framecalm presetsRecommended, Competitive, Extreme

The trade-off

You can still use Copilot in a browser.

Exactly what it changes

  • HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot\TurnOffWindowsCopilotSet to 1 · Windows default: not set (the value doesn't exist)

Do it by hand

Open Command Prompt as administrator and run:

reg add "HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot" /v "TurnOffWindowsCopilot" /t REG_DWORD /d 1 /f

To undo it:

reg delete "HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot" /v "TurnOffWindowsCopilot" /f

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
