Turn off Spectre and Meltdown protections

Extreme · Fixes specific problems · Windows 10 and 11

What it does

Removes the CPU security patches that slow down older Intel processors, mostly 6th to 9th generation. Newer CPUs fix this in hardware and gain little.

CategorySystem and security
TierExtreme: turns off a Windows protection or feature. Only for people who know what they give up.
Expected differenceFixes specific problems
Needs adminYes
RestartNeeded before it takes effect
Framecalm presetsNot in a preset. Pick it yourself.

The trade-off

Malicious code, including in a web page, could read memory it shouldn't. Only for a PC used for games and nothing sensitive. Takes effect after a restart.

Exactly what it changes

  • HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management\FeatureSettingsOverrideSet to 3 · Windows default: not set (the value doesn't exist)
  • HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management\FeatureSettingsOverrideMaskSet to 3 · Windows default: not set (the value doesn't exist)

Do it by hand

Open Command Prompt as administrator and run:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v "FeatureSettingsOverride" /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v "FeatureSettingsOverrideMask" /t REG_DWORD /d 3 /f

To undo it:

reg delete "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v "FeatureSettingsOverride" /f
reg delete "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v "FeatureSettingsOverrideMask" /f

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
