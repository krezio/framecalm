Keep USB devices awake

Safe · Fixes specific problems · Windows 10 and 11

What it does

Stops Windows putting USB ports to sleep to save power. Fixes mice, headsets and controllers that drop out or lag for a moment after sitting idle.

CategoryPower and CPU
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceFixes specific problems
Needs adminYes
RestartNot needed
Framecalm presetsRecommended, Competitive, Extreme

The trade-off

Laptops use slightly more battery.

Exactly what it changes

  • powercfg USB settings / USB selective suspendSet to 0 · Windows default: 1

Do it by hand

Open Command Prompt as administrator and run:

powercfg /setacvalueindex SCHEME_CURRENT 2a737441-1930-4402-8d77-b2bebba308a3 48e6b7a6-50f5-4782-a5d4-53bb8f07e226 0
powercfg /setdcvalueindex SCHEME_CURRENT 2a737441-1930-4402-8d77-b2bebba308a3 48e6b7a6-50f5-4782-a5d4-53bb8f07e226 0
powercfg /setactive SCHEME_CURRENT

To undo it:

powercfg /setacvalueindex SCHEME_CURRENT 2a737441-1930-4402-8d77-b2bebba308a3 48e6b7a6-50f5-4782-a5d4-53bb8f07e226 1
powercfg /setdcvalueindex SCHEME_CURRENT 2a737441-1930-4402-8d77-b2bebba308a3 48e6b7a6-50f5-4782-a5d4-53bb8f07e226 1
powercfg /setactive SCHEME_CURRENT

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.

More power and cpu tweaks

  • Turn off Fast Startup

    Fast Startup makes Shut down a half-hibernate, so drivers and Windows never get a clean start.

  • Keep the CPU at full speed

    Sets the minimum processor state to 100%, so the CPU doesn't have to ramp its clock up when a game suddenly needs it.

  • Turn off core parking

    Keeps every CPU core available instead of letting Windows park idle ones.

  • Aggressive CPU boost

    Tells the CPU to use its turbo boost as soon as there's work, rather than waiting to see if the load sticks around.

  • Turn off PCI Express power saving

    Stops Windows lowering the power state of the link to your graphics card and NVMe drive between bursts of work.

  • Turn off power throttling

    Windows slows down apps it thinks are in the background.

  • Turn off hibernation

    Removes the hibernation file, which is often 6 to 25 GB on drive C:.

  • Keep drives spinning

    Stops Windows powering down drives after a few minutes idle, so a game doesn't hitch while a hard drive spins back up.

  • CPU energy preference: performance

    Tells the processor to favour speed over saving energy when it decides how fast to run.

  • Never let the CPU idle

    Keeps every core out of its sleep states.
