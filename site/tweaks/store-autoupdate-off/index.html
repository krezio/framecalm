Stop Store apps updating in the background

Advanced · Small gain · Windows 10 and 11

What it does

Microsoft Store apps stop downloading updates on their own while you play.

CategoryNetwork
TierAdvanced: trades some power use or a convenience for lower latency.
Expected differenceSmall gain
Needs adminYes
RestartNot needed
Framecalm presetsExtreme

The trade-off

You update Store apps yourself from the Store's Library page. Games from the Xbox app are affected too.

Exactly what it changes

  • HKLM\SOFTWARE\Policies\Microsoft\WindowsStore\AutoDownloadSet to 2 · Windows default: not set (the value doesn't exist)

Do it by hand

Open Command Prompt as administrator and run:

reg add "HKLM\SOFTWARE\Policies\Microsoft\WindowsStore" /v "AutoDownload" /t REG_DWORD /d 2 /f

To undo it:

reg delete "HKLM\SOFTWARE\Policies\Microsoft\WindowsStore" /v "AutoDownload" /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
