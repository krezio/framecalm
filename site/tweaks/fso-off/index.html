Turn off fullscreen optimizations everywhere

Advanced · Fixes specific problems · Windows 10 and 11

What it does

Makes fullscreen games use real exclusive fullscreen instead of a borderless window in disguise. Some older DirectX 11 games feel more responsive this way.

CategoryGraphics
TierAdvanced: trades some power use or a convenience for lower latency.
Expected differenceFixes specific problems
Needs adminNo, it's a per-user setting
RestartNot needed
Framecalm presetsExtreme

The trade-off

Alt-Tab is slower and some overlays won't show over the game.

Exactly what it changes

  • HKCU\System\GameConfigStore\GameDVR_FSEBehaviorModeSet to 2 · Windows default: 0
  • HKCU\System\GameConfigStore\GameDVR_HonorUserFSEBehaviorModeSet to 1 · Windows default: 0
  • HKCU\System\GameConfigStore\GameDVR_DXGIHonorFSEWindowsCompatibleSet to 1 · Windows default: 0

Do it by hand

Open Command Prompt and run:

reg add "HKCU\System\GameConfigStore" /v "GameDVR_FSEBehaviorMode" /t REG_DWORD /d 2 /f
reg add "HKCU\System\GameConfigStore" /v "GameDVR_HonorUserFSEBehaviorMode" /t REG_DWORD /d 1 /f
reg add "HKCU\System\GameConfigStore" /v "GameDVR_DXGIHonorFSEWindowsCompatible" /t REG_DWORD /d 1 /f

To undo it:

reg add "HKCU\System\GameConfigStore" /v "GameDVR_FSEBehaviorMode" /t REG_DWORD /d 0 /f
reg add "HKCU\System\GameConfigStore" /v "GameDVR_HonorUserFSEBehaviorMode" /t REG_DWORD /d 0 /f
reg add "HKCU\System\GameConfigStore" /v "GameDVR_DXGIHonorFSEWindowsCompatible" /t REG_DWORD /d 0 /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.

More graphics tweaks

  • Hardware-accelerated GPU scheduling

    Lets the graphics card manage its own memory and scheduling.

  • Turn off Xbox Game Bar

    Stops the Game Bar overlay and its capture features from hooking into every game you start.

  • No Game Bar pop-ups

    Stops the "Press Win+G" tip from showing when a game starts.

  • Prioritize games in the multimedia scheduler

    Windows has a scheduler profile just for games that it barely uses by default.

  • Give games more CPU time

    Windows reserves 20% of CPU time for background tasks while multimedia apps run.

  • Favor the window you're using

    Gives the app in front shorter, more frequent turns on the CPU, so a game gets scheduled sooner after input.

  • Turn off multiplane overlay

    A known fix for flicker, black flashes and stutter on some NVIDIA multi-monitor setups.

  • Block Game DVR everywhere

    Turns off Windows game recording with a policy, so no app or update can switch it back on.

  • Longer GPU timeout

    Gives the graphics driver 10 seconds instead of 2 before Windows decides it has hung and resets it.

  • Turn off Fault Tolerant Heap

    If a game crashes a few times, Windows quietly runs it with a slower, safer memory allocator from then on.
