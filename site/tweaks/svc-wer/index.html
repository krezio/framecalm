Disable error reporting

Advanced · Small gain · Windows 10 and 11

What it does

Crashes are no longer collected and uploaded in the background.

CategoryServices
TierAdvanced: trades some power use or a convenience for lower latency.
Expected differenceSmall gain
Needs adminYes
RestartNeeded before it takes effect
Framecalm presetsCompetitive, Extreme

The trade-off

Microsoft and app makers don't get your crash reports, so fixes for your exact crash may come later.

Exactly what it changes

  • HKLM\SYSTEM\CurrentControlSet\Services\WerSvc\StartSet to 4 (disabled) · Windows default: manual

Do it by hand

Open Command Prompt as administrator and run:

sc config WerSvc start= disabled

To undo it:

sc config WerSvc start= demand

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
