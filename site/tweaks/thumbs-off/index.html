Icons instead of thumbnails

Advanced · Small gain · Windows 10 and 11

What it does

File Explorer shows file icons instead of generating thumbnails, which speeds up big photo and video folders.

CategoryLook and feel
TierAdvanced: trades some power use or a convenience for lower latency.
Expected differenceSmall gain
Needs adminNo, it's a per-user setting
RestartNot needed
Framecalm presetsExtreme

The trade-off

You can't preview images by their thumbnails.

Exactly what it changes

  • HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\IconsOnlySet to 1 · Windows default: 0

Do it by hand

Open Command Prompt and run:

reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "IconsOnly" /t REG_DWORD /d 1 /f

To undo it:

reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "IconsOnly" /t REG_DWORD /d 0 /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
