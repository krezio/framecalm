Graphics tweaks

How Windows schedules the GPU and presents frames from games. 11 tweaks: 3 safe, 8 advanced, 0 extreme.

  • Hardware-accelerated GPU scheduling

    Safe · Fixes specific problems. Lets the graphics card manage its own memory and scheduling. Required for DLSS Frame Generation; on other games the effect is small either way.

  • Turn off Xbox Game Bar

    Safe · Small gain. Stops the Game Bar overlay and its capture features from hooking into every game you start.

  • No Game Bar pop-ups

    Safe · Small gain. Stops the "Press Win+G" tip from showing when a game starts.

  • Prioritize games in the multimedia scheduler

    Advanced · Small gain. Windows has a scheduler profile just for games that it barely uses by default. This raises its CPU priority and I/O priority to High.

  • Give games more CPU time

    Advanced · Small gain. Windows reserves 20% of CPU time for background tasks while multimedia apps run. This lowers the reservation to 10%.

  • Favor the window you're using

    Advanced · Small gain. Gives the app in front shorter, more frequent turns on the CPU, so a game gets scheduled sooner after input.

  • Turn off fullscreen optimizations everywhere

    Advanced · Fixes specific problems. Makes fullscreen games use real exclusive fullscreen instead of a borderless window in disguise. Some older DirectX 11 games feel more responsive this way.

  • Turn off multiplane overlay

    Advanced · Fixes specific problems. A known fix for flicker, black flashes and stutter on some NVIDIA multi-monitor setups. Leave it alone if you don't have those problems.

  • Block Game DVR everywhere

    Advanced · Small gain. Turns off Windows game recording with a policy, so no app or update can switch it back on.

  • Longer GPU timeout

    Advanced · Fixes specific problems. Gives the graphics driver 10 seconds instead of 2 before Windows decides it has hung and resets it. Fixes "display driver stopped responding" in heavy games and on overclocked cards.

  • Turn off Fault Tolerant Heap

    Advanced · Fixes specific problems. If a game crashes a few times, Windows quietly runs it with a slower, safer memory allocator from then on. This stops that.
