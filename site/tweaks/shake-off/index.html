No shake to minimize

Safe · Small gain · Windows 10 and 11

What it does

Shaking a window while you drag it no longer minimizes everything else.

CategoryMouse and keyboard
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceSmall gain
Needs adminNo, it's a per-user setting
RestartNot needed
Framecalm presetsCompetitive, Extreme

The trade-off

None.

Exactly what it changes

  • HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\DisallowShakingSet to 1 · Windows default: not set (the value doesn't exist)

Do it by hand

Open Command Prompt and run:

reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "DisallowShaking" /t REG_DWORD /d 1 /f

To undo it:

reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "DisallowShaking" /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
