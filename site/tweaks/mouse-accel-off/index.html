Turn off mouse acceleration

Safe · Big difference · Windows 10 and 11

What it does

Turns off Enhance pointer precision, so the same hand movement always moves the same distance. The single biggest change for aim consistency.

CategoryMouse and keyboard
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceBig difference
Needs adminNo, it's a per-user setting
RestartNeeded before it takes effect
Framecalm presetsRecommended, Competitive, Extreme

The trade-off

The desktop pointer feels slower at first. Takes effect after you sign out.

Exactly what it changes

  • HKCU\Control Panel\Mouse\MouseSpeedSet to "0" · Windows default: "1"
  • HKCU\Control Panel\Mouse\MouseThreshold1Set to "0" · Windows default: "6"
  • HKCU\Control Panel\Mouse\MouseThreshold2Set to "0" · Windows default: "10"

Do it by hand

Open Command Prompt and run:

reg add "HKCU\Control Panel\Mouse" /v "MouseSpeed" /t REG_SZ /d "0" /f
reg add "HKCU\Control Panel\Mouse" /v "MouseThreshold1" /t REG_SZ /d "0" /f
reg add "HKCU\Control Panel\Mouse" /v "MouseThreshold2" /t REG_SZ /d "0" /f

To undo it:

reg add "HKCU\Control Panel\Mouse" /v "MouseSpeed" /t REG_SZ /d "1" /f
reg add "HKCU\Control Panel\Mouse" /v "MouseThreshold1" /t REG_SZ /d "6" /f
reg add "HKCU\Control Panel\Mouse" /v "MouseThreshold2" /t REG_SZ /d "10" /f

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
