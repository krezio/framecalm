Mouse and keyboard tweaks

Raw, predictable input with no pop-ups that steal focus mid-game. 5 tweaks: 5 safe, 0 advanced, 0 extreme.

  • Turn off mouse acceleration

    Safe · Big difference. Turns off Enhance pointer precision, so the same hand movement always moves the same distance. The single biggest change for aim consistency.

  • No Sticky Keys pop-up

    Safe · Fixes specific problems. Pressing Shift five times no longer throws you out of the game to ask about Sticky Keys. Same for Filter Keys and Toggle Keys.

  • Shortest key repeat delay

    Safe · Small gain. Holding a key starts repeating sooner. Mostly noticeable in menus, chat and text.

  • No shake to minimize

    Safe · Small gain. Shaking a window while you drag it no longer minimizes everything else.

  • No typing insights

    Safe · Small gain. Windows stops collecting statistics about how you type.
