Turn off window animations

Safe · Small gain · Windows 10 and 11

What it does

Windows open, close and minimize instantly instead of animating.

CategoryLook and feel
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceSmall gain
Needs adminNo, it's a per-user setting
RestartNeeded before it takes effect
Framecalm presetsCompetitive, Extreme

The trade-off

Less polish. Takes effect after you sign out.

Exactly what it changes

  • HKCU\Control Panel\Desktop\WindowMetrics\MinAnimateSet to "0" · Windows default: "1"
  • HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\TaskbarAnimationsSet to 0 · Windows default: 1

Do it by hand

Open Command Prompt and run:

reg add "HKCU\Control Panel\Desktop\WindowMetrics" /v "MinAnimate" /t REG_SZ /d "0" /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "TaskbarAnimations" /t REG_DWORD /d 0 /f

To undo it:

reg add "HKCU\Control Panel\Desktop\WindowMetrics" /v "MinAnimate" /t REG_SZ /d "1" /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v "TaskbarAnimations" /t REG_DWORD /d 1 /f

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
