Hardware-accelerated GPU scheduling

Safe · Fixes specific problems · Windows 10 and 11

What it does

Lets the graphics card manage its own memory and scheduling. Required for DLSS Frame Generation; on other games the effect is small either way.

CategoryGraphics
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceFixes specific problems
Needs adminYes
RestartNeeded before it takes effect
Framecalm presetsRecommended, Competitive, Extreme

The trade-off

A few older drivers and capture tools behave badly with it. Takes effect after a restart.

Exactly what it changes

  • HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\HwSchModeSet to 2 · Windows default: 1

Do it by hand

Open Command Prompt as administrator and run:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers" /v "HwSchMode" /t REG_DWORD /d 2 /f

To undo it:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers" /v "HwSchMode" /t REG_DWORD /d 1 /f

Restart Windows afterwards. Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.

More graphics tweaks

  • Turn off Xbox Game Bar

    Stops the Game Bar overlay and its capture features from hooking into every game you start.

  • No Game Bar pop-ups

    Stops the "Press Win+G" tip from showing when a game starts.

  • Prioritize games in the multimedia scheduler

    Windows has a scheduler profile just for games that it barely uses by default.

  • Give games more CPU time

    Windows reserves 20% of CPU time for background tasks while multimedia apps run.

  • Favor the window you're using

    Gives the app in front shorter, more frequent turns on the CPU, so a game gets scheduled sooner after input.

  • Turn off fullscreen optimizations everywhere

    Makes fullscreen games use real exclusive fullscreen instead of a borderless window in disguise.

  • Turn off multiplane overlay

    A known fix for flicker, black flashes and stutter on some NVIDIA multi-monitor setups.

  • Block Game DVR everywhere

    Turns off Windows game recording with a policy, so no app or update can switch it back on.

  • Longer GPU timeout

    Gives the graphics driver 10 seconds instead of 2 before Windows decides it has hung and resets it.

  • Turn off Fault Tolerant Heap

    If a game crashes a few times, Windows quietly runs it with a slower, safer memory allocator from then on.
