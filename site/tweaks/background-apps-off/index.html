Stop apps running in the background

Safe · Noticeable · Windows 10 and 11

What it does

Store apps such as Weather, Phone Link and Mail stop running when they're closed.

CategoryBackground apps
TierSafe: a clear benefit and nothing most people would miss.
Expected differenceNoticeable
Needs adminNo, it's a per-user setting
RestartNot needed
Framecalm presetsRecommended, Competitive, Extreme

The trade-off

Those apps won't show live notifications until you open them.

Exactly what it changes

  • HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications\GlobalUserDisabledSet to 1 · Windows default: not set (the value doesn't exist)

Do it by hand

Open Command Prompt and run:

reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications" /v "GlobalUserDisabled" /t REG_DWORD /d 1 /f

To undo it:

reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications" /v "GlobalUserDisabled" /f

Make a restore point first if you're changing several things at once. Framecalm does that for you, keeps the old values, and checks each one after writing it.
