Power and CPU

How hard the processor is allowed to work, and what Windows switches off to save energy.

  • Keep USB devices awakeFixes specific problemsSafe

    Stops Windows putting USB ports to sleep to save power. Fixes mice, headsets and controllers that drop out or lag for a moment after sitting idle.

    Trade-off. Laptops use slightly more battery.

    • powercfg USB settings / USB selective suspendset to 0
  • Turn off Fast StartupFixes specific problemsSafe

    Fast Startup makes Shut down a half-hibernate, so drivers and Windows never get a clean start. Turning it off means Shut down really shuts down.

    Trade-off. Cold boots take a few seconds longer.

    • HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Power\HiberbootEnabledset to 0
  • Keep the CPU at full speedSmall gainAdvanced

    Sets the minimum processor state to 100%, so the CPU doesn't have to ramp its clock up when a game suddenly needs it.

    Trade-off. More heat and power use at idle. On laptops, fans may spin more.

    • powercfg SUB_PROCESSOR / PROCTHROTTLEMINset to 100
  • Turn off core parkingSmall gainAdvanced

    Keeps every CPU core available instead of letting Windows park idle ones. Can smooth out frame times when a game's load jumps between cores.

    Trade-off. Higher idle power use.

    • powercfg SUB_PROCESSOR / CPMINCORESset to 100
  • Aggressive CPU boostSmall gainAdvanced

    Tells the CPU to use its turbo boost as soon as there's work, rather than waiting to see if the load sticks around.

    Trade-off. Runs hotter. On thin laptops it can hit thermal limits sooner.

    • powercfg SUB_PROCESSOR / PERFBOOSTMODEset to 2
  • Turn off PCI Express power savingSmall gainAdvanced

    Stops Windows lowering the power state of the link to your graphics card and NVMe drive between bursts of work.

    Trade-off. A few watts more at idle.

    • powercfg SUB_PCIEXPRESS / ASPMset to 0
  • Turn off power throttlingSmall gainAdvanced

    Windows slows down apps it thinks are in the background. This stops it, which helps when a game's launcher, voice chat or capture app gets throttled.

    Trade-off. Background apps use more power. Takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Control\Power\PowerThrottling\PowerThrottlingOffset to 1
  • Turn off hibernationFixes specific problemsAdvanced

    Removes the hibernation file, which is often 6 to 25 GB on drive C:. Also turns off Fast Startup.

    Trade-off. No Hibernate option. Laptops that hibernate on low battery will shut down instead.

    • HKLM\SYSTEM\CurrentControlSet\Control\Power\HibernateEnabledset to 0
  • Keep drives spinningSmall gainAdvanced

    Stops Windows powering down drives after a few minutes idle, so a game doesn't hitch while a hard drive spins back up.

    Trade-off. Hard drives use a little more power and make a little more noise.

    • powercfg SUB_DISK / DISKIDLEset to 0
  • CPU energy preference: performanceSmall gainAdvanced

    Tells the processor to favour speed over saving energy when it decides how fast to run.

    Trade-off. More heat and power use, especially on laptops.

    • powercfg SUB_PROCESSOR / PERFEPPset to 0
  • Never let the CPU idleFixes specific problemsExtreme

    Keeps every core out of its sleep states. Shaves the wake-up delay some competitive players chase.

    Trade-off. The CPU runs hot and loud all the time and uses a lot more power. Never on a laptop.

    • powercfg SUB_PROCESSOR / IDLEDISABLEset to 1

Graphics

How Windows schedules the GPU and presents frames from games.

  • Hardware-accelerated GPU schedulingFixes specific problemsSafe

    Lets the graphics card manage its own memory and scheduling. Required for DLSS Frame Generation; on other games the effect is small either way.

    Trade-off. A few older drivers and capture tools behave badly with it. Takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\HwSchModeset to 2
  • Turn off Xbox Game BarSmall gainSafe

    Stops the Game Bar overlay and its capture features from hooking into every game you start.

    Trade-off. No Win+G overlay, no clips from Game Bar. Your own capture app is unaffected.

    • HKCU\Software\Microsoft\Windows\CurrentVersion\GameDVR\AppCaptureEnabledset to 0
    • HKCU\System\GameConfigStore\GameDVR_Enabledset to 0
    • HKCU\Software\Microsoft\GameBar\UseNexusForGameBarEnabledset to 0
  • No Game Bar pop-upsSmall gainSafe

    Stops the "Press Win+G" tip from showing when a game starts.

    Trade-off. None.

    • HKCU\Software\Microsoft\GameBar\ShowStartupPanelset to 0
  • Prioritize games in the multimedia schedulerSmall gainAdvanced

    Windows has a scheduler profile just for games that it barely uses by default. This raises its CPU priority and I/O priority to High.

    Trade-off. Background audio or streaming apps can get less time while a game runs.

    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks\Games\Priorityset to 6
    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks\Games\Scheduling Categoryset to "High"
    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks\Games\SFIO Priorityset to "High"
  • Give games more CPU timeSmall gainAdvanced

    Windows reserves 20% of CPU time for background tasks while multimedia apps run. This lowers the reservation to 10%.

    Trade-off. Background tasks get less time during games.

    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\SystemResponsivenessset to 10
  • Favor the window you're usingSmall gainAdvanced

    Gives the app in front shorter, more frequent turns on the CPU, so a game gets scheduled sooner after input.

    Trade-off. Background work such as encoding or downloads can run a little slower.

    • HKLM\SYSTEM\CurrentControlSet\Control\PriorityControl\Win32PrioritySeparationset to 38
  • Turn off fullscreen optimizations everywhereFixes specific problemsAdvanced

    Makes fullscreen games use real exclusive fullscreen instead of a borderless window in disguise. Some older DirectX 11 games feel more responsive this way.

    Trade-off. Alt-Tab is slower and some overlays won't show over the game.

    • HKCU\System\GameConfigStore\GameDVR_FSEBehaviorModeset to 2
    • HKCU\System\GameConfigStore\GameDVR_HonorUserFSEBehaviorModeset to 1
    • HKCU\System\GameConfigStore\GameDVR_DXGIHonorFSEWindowsCompatibleset to 1
  • Turn off multiplane overlayFixes specific problemsAdvanced

    A known fix for flicker, black flashes and stutter on some NVIDIA multi-monitor setups. Leave it alone if you don't have those problems.

    Trade-off. Slightly higher GPU use for video playback. Takes effect after a restart.

    • HKLM\SOFTWARE\Microsoft\Windows\Dwm\OverlayTestModeset to 5
  • Block Game DVR everywhereSmall gainAdvanced

    Turns off Windows game recording with a policy, so no app or update can switch it back on.

    Trade-off. Xbox Game Bar can't record clips at all.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\GameDVR\AllowGameDVRset to 0
  • Longer GPU timeoutFixes specific problemsAdvanced

    Gives the graphics driver 10 seconds instead of 2 before Windows decides it has hung and resets it. Fixes "display driver stopped responding" in heavy games and on overclocked cards.

    Trade-off. A genuinely frozen GPU takes longer to recover. Takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\TdrDelayset to 10
  • Turn off Fault Tolerant HeapFixes specific problemsAdvanced

    If a game crashes a few times, Windows quietly runs it with a slower, safer memory allocator from then on. This stops that.

    Trade-off. A game that really is unstable may crash more often instead of running slower.

    • HKLM\SOFTWARE\Microsoft\FTH\Enabledset to 0

Network

Latency and background bandwidth: what else is using your connection while you play.

  • Stop sharing updates with other PCsNoticeableSafe

    By default Windows can upload update files to other PCs. On a slow upload connection that shows up as ping spikes. Updates still download from Microsoft.

    Trade-off. None for most people.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization\DODownloadModeset to 0
  • Turn off Remote AssistanceSmall gainSafe

    Stops other people being invited to view or control this PC through Remote Assistance. Fewer open doors.

    Trade-off. You can't receive help through Remote Assistance until you turn it back on.

    • HKLM\SYSTEM\CurrentControlSet\Control\Remote Assistance\fAllowToGetHelpset to 0
  • Turn off network throttlingSmall gainAdvanced

    Windows limits network processing while media plays so audio doesn't glitch. This removes the limit.

    Trade-off. On very old CPUs, audio can crackle under heavy network load.

    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\NetworkThrottlingIndexset to 0xFFFFFFFF
  • Turn off Nagle's algorithmFixes specific problemsAdvanced

    Sends small packets right away instead of bundling them. Helps games that use TCP (some MMOs and older titles). Most shooters use UDP and won't change.

    Trade-off. A little more network overhead. Applies to your active network adapters; takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\{each network adapter}\TcpAckFrequencyset to 1
    • HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\{each network adapter}\TCPNoDelayset to 1
  • Stop Store apps updating in the backgroundSmall gainAdvanced

    Microsoft Store apps stop downloading updates on their own while you play.

    Trade-off. You update Store apps yourself from the Store's Library page. Games from the Xbox app are affected too.

    • HKLM\SOFTWARE\Policies\Microsoft\WindowsStore\AutoDownloadset to 2
  • Keep Windows Update away from driversFixes specific problemsAdvanced

    Stops Windows Update replacing your graphics driver with an older or generic one.

    Trade-off. You update drivers yourself, from NVIDIA, AMD or Intel.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\ExcludeWUDriversInQualityUpdateset to 1
  • Ask before downloading Windows updatesNoticeableAdvanced

    Windows tells you updates are ready instead of downloading and installing them in the middle of a session.

    Trade-off. Security updates wait for you. Install them regularly.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU\AUOptionsset to 2
    • HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU\NoAutoRebootWithLoggedOnUsersset to 1
  • Prefer IPv4 over IPv6Fixes specific problemsAdvanced

    Some games and launchers connect faster or more reliably over IPv4. IPv6 still works when it's the only option.

    Trade-off. None for most people. Takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Services\Tcpip6\Parameters\DisabledComponentsset to 32
  • Faster copies over your home networkFixes specific problemsAdvanced

    Turns off bandwidth throttling for file sharing, so copying from a NAS or another PC isn't held back.

    Trade-off. None on a home network.

    • HKLM\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters\DisableBandwidthThrottlingset to 1

Mouse and keyboard

Raw, predictable input with no pop-ups that steal focus mid-game.

  • Turn off mouse accelerationBig differenceSafe

    Turns off Enhance pointer precision, so the same hand movement always moves the same distance. The single biggest change for aim consistency.

    Trade-off. The desktop pointer feels slower at first. Takes effect after you sign out.

    • HKCU\Control Panel\Mouse\MouseSpeedset to "0"
    • HKCU\Control Panel\Mouse\MouseThreshold1set to "0"
    • HKCU\Control Panel\Mouse\MouseThreshold2set to "0"
  • No Sticky Keys pop-upFixes specific problemsSafe

    Pressing Shift five times no longer throws you out of the game to ask about Sticky Keys. Same for Filter Keys and Toggle Keys.

    Trade-off. None. You can still turn these on in Accessibility settings.

    • HKCU\Control Panel\Accessibility\StickyKeys\Flagsset to "506"
    • HKCU\Control Panel\Accessibility\Keyboard Response\Flagsset to "122"
    • HKCU\Control Panel\Accessibility\ToggleKeys\Flagsset to "58"
  • Shortest key repeat delaySmall gainSafe

    Holding a key starts repeating sooner. Mostly noticeable in menus, chat and text.

    Trade-off. Easier to type a letter twice by accident. Takes effect after you sign out.

    • HKCU\Control Panel\Keyboard\KeyboardDelayset to "0"
  • No shake to minimizeSmall gainSafe

    Shaking a window while you drag it no longer minimizes everything else.

    Trade-off. None.

    • HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\DisallowShakingset to 1
  • No typing insightsSmall gainSafe

    Windows stops collecting statistics about how you type.

    Trade-off. None.

    • HKCU\Software\Microsoft\Input\Settings\InsightsEnabledset to 0

Background apps

Apps and features that run when you didn't ask them to.

  • Stop apps running in the backgroundNoticeableSafe

    Store apps such as Weather, Phone Link and Mail stop running when they're closed.

    Trade-off. Those apps won't show live notifications until you open them.

    • HKCU\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications\GlobalUserDisabledset to 1
  • Stop Microsoft Edge running in the backgroundNoticeableSafe

    Edge preloads itself at sign-in and keeps running after you close it. This stops both.

    Trade-off. Edge opens about a second slower.

    • HKLM\SOFTWARE\Policies\Microsoft\Edge\StartupBoostEnabledset to 0
    • HKLM\SOFTWARE\Policies\Microsoft\Edge\BackgroundModeEnabledset to 0
  • Turn off WidgetsNoticeableSafe

    Removes the Widgets board and the news feed process that keeps it filled.

    Trade-off. No weather or news on the taskbar.

    • HKLM\SOFTWARE\Policies\Microsoft\Dsh\AllowNewsAndInterestsset to 0
  • Turn off Copilot in WindowsSmall gainSafe

    Removes the Copilot sidebar and its background process.

    Trade-off. You can still use Copilot in a browser.

    • HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot\TurnOffWindowsCopilotset to 1
  • No startup delaySmall gainSafe

    Windows waits about ten seconds after sign-in before starting your startup apps. This removes the wait.

    Trade-off. If you have many startup apps, they all compete for the first few seconds.

    • HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Serialize\StartupDelayInMSecset to 0
  • Turn off RecallNoticeableSafe

    Stops Windows taking snapshots of your screen to make your activity searchable, on PCs that support it.

    Trade-off. No Recall timeline.

    • HKCU\Software\Policies\Microsoft\Windows\WindowsAI\DisableAIDataAnalysisset to 1
  • Turn off CortanaSmall gainSafe

    Removes Cortana and its background process on Windows versions that still include it.

    Trade-off. None.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search\AllowCortanaset to 0
  • No feedback requestsSmall gainSafe

    Windows stops asking how it's doing.

    Trade-off. None.

    • HKCU\Software\Microsoft\Siuf\Rules\NumberOfSIUFInPeriodset to 0
  • Turn off OneDriveNoticeableAdvanced

    Stops OneDrive starting and syncing in the background, which can eat disk and upload bandwidth mid-game.

    Trade-off. Files stop syncing to OneDrive. Files already on this PC stay where they are.

    • HKLM\SOFTWARE\Policies\Microsoft\Windows\OneDrive\DisableFileSyncNGSCset to 1
  • Turn off automatic maintenanceNoticeableExtreme

    Stops Windows' nightly maintenance (disk optimization, scans, update cleanup) starting while the PC is idle, which can spill into a gaming session.

    Trade-off. SSD TRIM and update cleanup no longer run on their own. Run Optimize Drives yourself every few weeks.

    • HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\Maintenance\MaintenanceDisabledset to 1

    • HKLM\SYSTEM\CurrentControlSet\Services\RetailDemo\Startset to 4 (disabled)

    Disables Windows Media Player's network sharing service.

  • Disable Payments and NFCSmall gainSafe

    Disables a diagnostics collector used by developer tools.

  • Disable SysMain (Superfetch)Fixes specific problemsAdvanced

    SysMain preloads apps into memory based on what you use. On an SSD the gain is small, and on some PCs it causes bursts of disk use.

    Trade-off. Apps you open often may start a little slower, especially from a hard drive. Takes effect after a restart.

    • HKLM\SYSTEM\CurrentControlSet\Services\SysMain\Startset to 4 (disabled)
  • Disable Windows Search indexingNoticeableAdvanced

  • Disable error reportingSmall gainAdvanced

  • Disable Xbox servicesSmall gainAdvanced

    Trade-off. Game Pass, Xbox app games and Xbox controllers' extra features stop working. Skip this if you use any of them.

    • HKLM\SYSTEM\CurrentControlSet\Services\XblAuthManager\Startset to 4 (disabled)
    • HKLM\SYSTEM\CurrentControlSet\Services\XblGameSave\Startset to 4 (disabled)
    • HKLM\SYSTEM\CurrentControlSet\Services\XboxNetApiSvc\Startset to 4 (disabled)
    • HKLM\SYSTEM\CurrentControlSet\Services\XboxGipSvc\Startset to 4 (disabled)
  • Disable location serviceSmall gainAdvanced

    Disables the service apps use to find where you are.

    • HKLM\SYSTEM\CurrentControlSet\Services\lfsvc\Startset to 4 (disabled)
  • Disable compatibility assistantSmall gainAdvanced

    Stops Windows watching programs for compatibility problems and offering to re-run them with fixes.

    Trade-off. No automatic compatibility prompts for old programs.

    • HKLM\SYSTEM\CurrentControlSet\Services\PcaSvc\Startset to 4 (disabled)
  • Disable mobile hotspotSmall gainAdvanced

    • HKLM\SYSTEM\CurrentControlSet\Services\icssvc\Startset to 4 (disabled)

    Trade-off. Troubleshooters in Settings won't work.

    • HKLM\SYSTEM\CurrentControlSet\Services\DPS\Startset to 4 (disabled)

System and security

Deep changes to how Windows protects itself. Real gains on some CPUs, real trade-offs on all of them.

  • Stop recording file access timesSmall gainAdvanced

    Windows writes a timestamp every time a file is read. Turning that off cuts small writes during loading screens.

    Trade-off. Backup and cleanup tools that sort by last opened lose that information.

    • HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\NtfsDisableLastAccessUpdateset to 2147483649
  • Stop creating short file namesSmall gainAdvanced

    Windows creates an old DOS-style short name for every new file. Turning that off saves work in folders with thousands of files.

    Trade-off. Very old 16-bit programs may not find files. Existing short names stay.

    • HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\NtfsDisable8dot3NameCreationset to 1
  • Turn off Memory Integrity and VBSNoticeableExtreme

What we left out,on purpose.

RAM cleaners
Windows already uses free memory as cache. Emptying it makes the next load slower, not faster.
Turning off Windows Defender
Tamper Protection switches it back on, and the scan cost during games is small. Add your game folders as exclusions in Windows Security instead.
HPET, dynamic tick and platform clock (bcdedit)
On current hardware these make no difference or make frame times worse.
TCP window, IRPStackSize and other network packs
Windows tunes these automatically and does it better than a fixed value.
Realtime process priority
It can starve the mouse, keyboard and audio drivers and freeze the PC.
Deleting services or Windows components
It can't be undone cleanly and breaks updates. Framecalm only switches services to Disabled.
Reserved bandwidth (QoS) tweaks
Windows doesn't actually hold back 20% of your bandwidth. Setting the limit to zero changes nothing for games.
Disabling paging executive or large system cache
Leftovers from Windows XP. On current Windows they either do nothing or take memory away from games.
