How to debloat Windows 11 safely (what to remove, and what to leave alone)

Updated November 2026 · 7 min read

Short answer

Uninstall apps you don't use from Settings, switch off startup apps you don't need, and turn off background features like widgets, tips and ad tracking. Leave Microsoft Store, Edge WebView2, Windows Update, Windows Security and the Xbox services you use alone. Avoid scripts that delete system components: you can't easily undo them, and updates can break.

"Debloating" means removing the extra apps and background features Windows ships with. Done carefully it frees memory, startup time and a bit of background CPU. Done with an aggressive script, it can break the Store, Windows Update or games that rely on Xbox services, and leave no easy way back.

1. Uninstall apps you don't use

Open Settings › Apps › Installed apps, sort by name, and remove what you don't use: preinstalled games, trial apps, news and weather apps, and anything your PC maker added. This is the safest debloat there is, because you can reinstall any of it from the Store.

2. Turn off startup apps

Settings › Apps › Startup (or Task Manager › Startup apps). Switch off launchers, updaters and chat apps you don't need the moment Windows starts. Keep your audio driver panel, touchpad driver and security software on.

3. Switch off background features

These cost a little memory and CPU each, and switching them off is fully reversible:

  • Widgets and the news feed
  • Background apps that run when you didn't open them
  • Tips and suggestions in Start and Settings
  • The advertising ID
  • Web results in Start search
  • Edge running in the background after you close it
  • Copilot and Recall, if you don't use them

What to leave alone

KeepWhy
Microsoft StoreUpdates many built-in apps, and you'll want it to reinstall anything you removed.
Edge WebView2 RuntimeMany apps and game launchers use it to draw their windows, even if you never open Edge.
Windows Update servicesSecurity fixes and drivers. Turning them off leaves you exposed and causes trouble later.
Windows Security (Defender)Tamper Protection turns it back on anyway, and you'd have no protection in between.
Xbox app and Xbox servicesGame Pass and many PC games use them for sign-in and saves. Only remove them if you never use either.

Why not just run a debloat script?

Many popular scripts remove system packages, delete services or block update servers in one go. Some of that can't be undone without reinstalling Windows, and the next big Windows update may fail or put things back half-working. If you use one, read exactly what it does first, and make a restore point.
