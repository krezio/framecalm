Hardware-accelerated GPU scheduling: should you turn it on for gaming?

Updated November 2026 · 4 min read

Short answer

Turn it on if you use DLSS Frame Generation, which needs it. For other games the difference is small and can go either way, so test it: if you see new stutter or a capture tool misbehaves, turn it back off. It needs a restart either way.

Normally Windows decides when each program gets time on the graphics card. Hardware-accelerated GPU scheduling (HAGS) hands that job to a scheduler on the GPU itself. The idea is a little less overhead and latency between the game and the screen.

When it helps

  • DLSS Frame Generation on NVIDIA RTX 40-series and newer requires it. The option is greyed out in games without it.
  • Some games show slightly better frame pacing, especially when the CPU is the bottleneck.

When to leave it off

  • Older drivers, or a GPU too old to support it (the switch won't appear at all).
  • If a capture or streaming tool, or a VR setup, starts stuttering after you turn it on.
  • If your own before-and-after test shows worse 1% lows. It happens on some systems.

How to switch it

  1. Open Settings › System › Display › Graphics.
  2. On Windows 11, click Change default graphics settings (or Advanced graphics settings). On Windows 10 it's Graphics settings under Display.
  3. Switch Hardware-accelerated GPU scheduling on or off, then restart.

If the switch isn't there, your GPU or driver doesn't support it. Update the graphics driver from NVIDIA, AMD or Intel first. Under the hood it's one registry value: here's the exact key.

Test it, don't trust it

Play the same scene with it off and on, after a restart each time, and compare 1% lows rather than average FPS. If you can't tell the difference, leave it on: it's the default on new Windows 11 installs with supported GPUs and it's required for frame generation.
