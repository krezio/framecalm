Is my game using the wrong GPU? How to check and fix it on Windows

Updated November 2026 · 5 min read

Short answer

Open Task Manager, add the GPU engine column and look at your game: GPU 0 is usually the integrated chip. To fix it, go to Settings → System → Display → Graphics, add the game and choose High performance.

Most gaming laptops have two GPUs: a small integrated one inside the processor (Intel Iris/UHD or AMD Radeon) that saves battery, and a dedicated one (NVIDIA GeForce, AMD Radeon RX) that's several times faster. Windows and the graphics driver decide which one each app uses. Usually they get games right. Sometimes they don't, and the game runs at a fraction of the frame rate it should.

Signs you're on the wrong GPU

  • FPS is far lower than other people report with the same laptop.
  • Lowering settings barely changes anything.
  • The laptop stays quiet and cool while gaming.
  • It's a game launched through Java (Minecraft), an emulator, or a launcher that starts another exe.

How to check

  1. Start the game, then press Ctrl + Shift + Esc to open Task Manager.
  2. On the Processes tab, right-click a column header and turn on GPU engine.
  3. Find the game. If it says GPU 0, check the Performance tab to see which chip GPU 0 is. On most laptops GPU 0 is the integrated one.

How to fix it in Windows

  1. Open Settings → System → Display → Graphics.
  2. Find the game in the list, or click Browse and pick the game's .exe (for Minecraft, that's the javaw.exe the launcher uses).
  3. Choose High performance and save. Restart the game.

This is a per-app setting stored for your user account, and you can set it back to Let Windows decide any time.

Other things that force the slow GPU

  • Battery power. Many laptops limit the dedicated GPU heavily on battery. Plug in.
  • MUX switch / Advanced Optimus. If your laptop has a "dGPU only" or "Ultimate" mode in its control app, using it removes the integrated chip from the path entirely, usually for a few extra percent.
  • External monitor port. On some laptops only certain ports are wired to the dedicated GPU (often the HDMI or a specific USB-C port).
