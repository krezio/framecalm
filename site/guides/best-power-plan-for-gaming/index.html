Best Windows power plan for gaming (Balanced vs High performance vs Ultimate)

Updated November 2026 · 5 min read

Short answer

On a desktop, High performance (or Ultimate Performance) keeps the CPU ready and avoids small hitches when it ramps up. On a laptop, plug in and set the Windows power mode to Best performance; forcing High performance on battery mostly adds heat. The biggest wins are usually elsewhere: the right GPU, the right refresh rate, and no power saving on USB and Wi-Fi.

A power plan is a bundle of settings that decide how eagerly Windows lets the processor speed up, how quickly it parks cores, and what it puts to sleep. The differences between plans are real but smaller than most "FPS boost" videos suggest. Here's what each one does and when it matters.

The plans, in plain English

PlanWhat it doesGood for
BalancedLets the CPU drop to low clocks when idle and boost quickly under load. On modern CPUs it boosts almost as fast as High performance.Laptops, and most desktops if you don't notice hitches
High performanceKeeps the minimum processor state high and parks fewer cores, so the CPU is already awake when a game asks for work.Desktops, competitive games, CPU-heavy games
Ultimate PerformanceHigh performance plus a few extra timers set to "never". Meant for workstations. Uses more power at idle.Desktops where every millisecond matters

How to switch

  1. Press Win + R, type powercfg.cpl and press Enter.
  2. Pick a plan. If you only see Balanced, click Show additional plans.
  3. On Windows 11 laptops, also open Settings › System › Power & battery and set Power mode to Best performance while plugged in.

Ultimate Performance is hidden by default. To add it, open Command Prompt as administrator and run:

powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61

It then shows up in the list. To see which plans you have, run powercfg /list.

Laptops: be careful

Laptops are limited by heat, not by how eagerly the CPU wakes up. Forcing the CPU to stay at high clocks makes the fans louder and can make the GPU throttle sooner, because they share the same cooler. Plug in, use Best performance, and spend the effort on the things that really cost laptops frames: running games on the integrated GPU and heat.

The settings inside the plan that matter more

  • USB selective suspend: turning it off stops mice and headsets dropping out after being idle.
  • Minimum processor state: 100% keeps the CPU ready, which is most of what High performance does.
  • Core parking: stops Windows putting cores to sleep mid-game.
  • Power throttling: stops Windows slowing down apps it thinks are in the background, like voice chat or a capture app.

How to know if it helped

Average FPS rarely moves much. Look at 1% lows and frame-time spikes instead: that's where a sleepy CPU shows up as stutter. Measure the same scene three times before and three times after. Here's how to measure FPS properly.
