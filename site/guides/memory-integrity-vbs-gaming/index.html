Memory Integrity and VBS: do they slow down games, and should you turn them off?

Updated November 2026 · 6 min read

Short answer

Virtualization-based security (VBS) and Memory Integrity can cost some CPUs around 5 to 15% in games, and Microsoft itself has said gamers can turn them off. But they protect Windows from a whole class of kernel-level malware, and some work devices and anti-cheats require them. Check whether they're on first, and only turn them off on a personal gaming PC if you accept that trade.

Windows 11 runs part of itself inside a small virtual machine to keep the most sensitive parts of the system out of reach of malware. That's virtualization-based security (VBS). Memory Integrity (also called HVCI) uses it to check every driver before it's allowed to run. Both are on by default on many new PCs.

Is it on?

  1. Press Win + R, type msinfo32 and press Enter.
  2. On the System Summary page, look for Virtualization-based security. "Running" means it's on.
  3. For Memory Integrity specifically: Windows Security › Device security › Core isolation details.

How much does it cost?

It depends a lot on the CPU. Older processors without fast support for the checks it does lose the most; very recent ones lose little. Tests on affected systems have shown roughly 5 to 15% lower FPS in some games. The only way to know for your PC is to measure the same scene with it on and off.

What you give up

  • Protection against malware that tries to load a malicious or vulnerable driver into the Windows kernel. That kind of attack is rare on home PCs, but it's serious when it happens.
  • Some work or school devices require it by policy. Don't change it on a PC you don't own.
  • A few anti-cheat systems and security tools expect it on. If a game complains after you turn it off, turn it back on.

How to turn Memory Integrity off

  1. Open Windows Security › Device security › Core isolation details.
  2. Switch Memory integrity off and restart.

That leaves VBS itself running on some PCs. Turning off both parts takes two registry values, listed exactly on the VBS off tweak page with the commands to undo it.

A sensible way to decide

  • Personal gaming PC, CPU a few years old, you keep Windows and drivers updated: worth testing with it off.
  • Work laptop, shared family PC, or you install a lot of random software: leave it on.
  • Very recent CPU: measure first. The gain may be too small to be worth it.
