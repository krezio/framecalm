Download Framecalm

Version 0.5.2. Free and open source. No account, no ads, no telemetry.

Download installer (.exe) Portable zip

Which one?

  • Installer: installs for your account only, so it doesn't need admin to install. Adds a Start menu entry and an uninstaller.
  • Portable: unzip anywhere and run Framecalm.exe. Nothing is installed. Delete the folder to remove it.

System requirements

WindowsWindows 10 (version 2004 or newer) or Windows 11, 64-bit
Memory4 GB or more
DiskAbout 200 MB
Admin rightsNot needed to install. Windows asks once per batch when you apply machine-wide settings.

"Windows protected your PC"

Windows SmartScreen shows this for new programs that aren't code-signed yet or haven't been downloaded many times. Click More info, then Run anyway. If you'd rather check first, the full source code is on GitHub and you can build it yourself.

After installing

  1. Open Framecalm. It looks at your PC first and changes nothing.
  2. Press Optimize now for the one-click plan, or open Tweaks and pick changes yourself.
  3. Everything you change is listed under History, where you can undo any of it.

Uninstalling

Open History and choose Undo everything if you want Windows exactly as it was, then remove Framecalm from Settings › Apps › Installed apps.
