Questions

Will this raise my FPS?

Some changes do, on some PCs: fixing a screen stuck at 60 Hz, pinning a game to the right GPU, turning off Memory Integrity. Most tweaks are about steadier frame times, lower input lag, or less going on in the background. Each one says how big a difference to expect, and Benchmarks lets you measure it on your own PC.

What does the one-click plan change?

It shows you a list first: PC fixes and tweaks picked for your hardware, each with a reason. Nothing changes until you press Apply, and you can untick any line.

Is it safe?

Safe tweaks are safe on any PC. Advanced ones trade power use or a convenience. Extreme ones switch off Windows protections, and the app asks you to confirm them. Whatever you pick, a restore point comes first and every value can be switched back.

Can it get me banned?

No. Framecalm changes Windows settings, not games. It never touches game files, memory, launch options or anti-cheat software.

Why does it ask for admin?

Most performance settings live in parts of the registry only an administrator can change. The main app runs as you. A small helper asks for admin once per batch and only accepts keys from the published list.

Does it cost anything?

No. Framecalm is free, with no account, no ads and no telemetry.

Can I see the code?

Yes. Framecalm is open source under the MIT license. The code, the full tweak catalog and the release builds are on GitHub, so you can check exactly what it does before you run it.

Does it work on Windows 10?

Yes. Framecalm runs on Windows 10 (version 2004 or newer) and Windows 11, 64-bit.

Does it work on laptops?

Yes. The one-click plan checks whether it's running on a laptop and skips tweaks that cost battery life or add heat. It can also pin games to the dedicated graphics card when a laptop keeps using the integrated one.

What's the difference between Safe, Advanced and Extreme?

Safe: a clear benefit and nothing most people would miss. Advanced: trades some power use or a convenience for lower latency. Extreme: turns off a Windows protection or feature. Only for people who know what they give up.

Which games does it support?

It finds games from Steam, Epic, Riot, Battle.net, the Xbox app, Minecraft and Roblox. It tunes the settings files of Minecraft Java, Fortnite and Rocket League for your hardware, and gives exact in-game steps for games with strict anti-cheat. The Windows tweaks help every game.

Windows SmartScreen warned me. Is it safe?

SmartScreen warns about new programs that aren't code-signed yet or haven't been downloaded much. Framecalm is open source, so you can read the code or build it yourself. Click More info, then Run anyway.

Does it need the internet?

No. It works offline. It can download game cover images and check for a newer version, and both can be switched off in Settings.

Where does it keep backups?

In %LOCALAPPDATA%\Framecalm on your PC: the original value of everything it changed, the history and its settings. Nothing is uploaded.

How do I uninstall it?

First open History and choose Undo everything if you want Windows exactly as it was. Then uninstall Framecalm from Settings, Apps, Installed apps. The portable version is just a folder you can delete.

What if a tweak causes a problem?

Open History and undo it: the exact old value is written back. If Windows won't start normally, use the restore point Framecalm made before the first change. Please also report it on GitHub so it can be fixed.
